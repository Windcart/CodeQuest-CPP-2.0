THE BIG IDEA
How does real C++ run here?
Your code is compiled by Clang to WebAssembly and runs in an isolated worker on this device. The first run downloads about 30 MB. Program input is supplied before a run. Stop cancels compilation or execution.
Robot replay shows robot actions, not every source line. Mission values are specific checks, not a general debugger. Console lessons support C++17 strings, vectors, references, structs, classes, and standard algorithms. Exceptions, threads, operating-system access, and external libraries are outside this runtime.
Some browser memory is needed for the compiler. Use a laptop or desktop for the best experience. Compiler credits
